GENESIS

Run, jump and duck through a level that has never existed before. Reach the beacon before the three-minute clock runs out.

Play now Level of the day

Genesis needs a keyboard, so play it on a desktop browser.

Why it's fun

Every run is a new level

Pits, spikes, laser bands, low tunnels and patrolling bugs are chained at random. Each level gets harder towards the end.

Share a level by its number

Every level has a seed. Send someone the link and they get exactly your level, then see who is faster.

Always finishable

A test bot plays 2,000 generated levels after every change. Every one of them can be beaten.

How it was built

  1. A one-page spec. Hero, controls, physics, obstacles, a 180-second timer and a neon look. No engine and no image files.
  2. Built by an AI coding agent in one pass. Wherever the spec left a question open, the agent made a sensible assumption and wrote it down.
  3. Tested by a bot, not by hand. A headless bot plays the real game logic and found the unfair spots before anyone played.
  4. Plain web tech. HTML5 canvas, vanilla JavaScript and CSS. Three files that run in any desktop browser.
Genesis is a live demo of an AI-assisted coding workflow.
